# Statement of AI Assistance

I used OpenAI Codex during this project.

**Code.** Codex helped explain errors, debug proofs, find Mathlib lemmas,
and generate or revise portions of the Lean definitions, theorem statements,
proofs, and checks. Its assistance covered Tseitin encoding, finite model
correspondence, weighted counting, probability, sensitivity, monotonicity,
and interval bounds. Examples include `toCNF_correct`
(`Tseitin/Completeness.lean`), `weightedModelCount_eq_weightedCNFModelCount`
(`Tseitin/Weighted.lean`), and `failureProbability_cnf_interval_bounds`
(`Tseitin/Intervals.lean`).

**Report.** Codex helped draft and revise the text, explain proof arguments,
develop examples, and edit the LaTeX source. It also helped prepare the
README and submission statements.
